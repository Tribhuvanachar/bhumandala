# dvaitavedanta.in raw pages

The HTTP cache from the crawl, exactly as fetched, so anything the
importer flattened away can still be recovered without re-crawling
(~14 hours at the source's ~39 s/leaf) and without asking the site
for it a second time.

Restore with: tar --use-compress-program=unzstd -xf dv-cache-raw.tar.zst
