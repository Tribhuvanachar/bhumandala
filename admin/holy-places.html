Which places are “holy”?
Curate every Brindavana / tīrtha in the dataset: set coordinates, approve or hide entries, and attach a licence-checked image. The holy-places JSON uses the shared shape the Tīrtha Prabandha “nearest holy place” finder consumes.
Shared data shape (Stream 4 contract). The holy-places JSON exports one record per place as {id, name, lat, lng, type, sourceDataset, approved, source, saint} plus the image fields image, image_page, image_credit, image_licence. Tīrtha Prabandha places should export the same shape with sourceDataset:"tirtha-prabandha" so both merge into one nearest-place finder. The Images JSON exports the Brindavana image registry (data/brindavana_images.json shape) to drop back into the Guru Parampara pipeline — the 2D/3D detail cards render image with its image_credit · image_licence caption once you fill and export it.

Licence rule: only paste an image URL after checking that specific file’s own licence tag on Wikimedia Commons (CC-BY / CC-BY-SA / CC0 / public-domain only). Record the licence in image_licence. Leave blank if nothing freely-licensed exists — never substitute an unrelated image.
