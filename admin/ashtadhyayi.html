Structured per-sūtra fields shown in the reader's ॥ पदच्छेद / विश्लेषण ॥ panel. Source: ashtadhyayi.com sutraani/data.txt + sutrartha_english.txt — padaccheda & anvaya come from the sūtra metadata, not from any single commentary layer. 👁 next to a field toggles it the same way as a layer above.

Coverage counts are read live from each layer's data.json. “Cleared (PD)” = public domain; “Permitted (curator)” = used under the ashtadhyayi.com curator's e-mail permission for non-commercial/educational use (source repo has no formal LICENSE) — keep attribution, resolve before public launch; “Verify” = sourced from the project lead's own StarDict dictionaries, edition/source not yet confirmed against a public copy. Licence resolution is a project-lead decision — this page only surfaces the status.
