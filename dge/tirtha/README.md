# Tīrtha Prabandha — Holy Places Database

A searchable / sortable / filterable atlas of the kṣetras named in Śrī Vādirāja
Tīrtha's *Tīrtha Prabandha*, arranged by direction (West → North → East → South),
with verse references and the *Guru-Bhāva-Prakāśikā* commentary.

## Files
- `index.html` — the app (self-contained; data is embedded, works offline)
- `data.json` — the underlying data (backbone for the rest of the DGE site)
- `tirtha_prabandha_places.csv` — same data as a spreadsheet
