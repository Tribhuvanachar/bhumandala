# Digital Grantha Engine (DGE)

Digital Grantha Engine is a modular web engine for reading, searching, studying and listening to Sanskrit granthas.

## Goals

- One engine
- Unlimited granthas
- Plugin architecture
- Offline capable
- Archive.org audio support
- AI-assisted study
- Multiple scripts
- Notes
- Bookmarks
- Commentary support
