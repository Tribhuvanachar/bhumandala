# Digital Grantha Engine (DGE)

## Current Structure

```
DGE/
├── index.html
├── config.json
├── assets/
└── data/
    ├── data_pns.json
    └── data_demo.json
```

## Design Goals

- Single `index.html`
- Config-driven
- Multiple granthas
- External audio (Archive.org or other host)
- GitHub Pages compatible
- Offline-friendly where possible

## Future Granthas

- Prahlada Kruta Narasimha Stotra
- Vishnu Sahasranama
- Bhagavad Gita
- Lakshmi Shobhane
