1. Upload PDF, Page Images, or Import from URL

A single PDF, or select multiple page-image files (JPG/PNG/WEBP) at once — pick them in reading order, since the order you select them in is the order they'll be OCR'd in. JP2 isn't supported yet (no browser can decode it without an extra library) — convert to JPG/PNG first.

⚠ Keep this tab open and in the foreground while OCR/Proofread are running — mobile browsers freeze background tabs' JavaScript entirely (switching apps, locking the screen) and no page can override that. Progress is saved after every single page/chunk, so if it does get interrupted, just reselect the same file and tap Resume/Proofread again — nothing already done gets redone.

2. Run OCR

Leave blank to OCR every page (default). Narrowing this also scopes step 3 (Proofread) to the same pages — useful for testing a few pages first, or re-running just the ones that failed, without redoing the whole book.

3. Proofread

Large books are sent to Gemini in chunks of this many pages, not all at once — smaller chunks are less likely to hit an output limit or produce malformed JSON. Default 8; lower it if a chunk keeps failing. If you're hitting a per-request quota limit instead, try RAISING this — fewer, bigger requests use up that quota more slowly.
